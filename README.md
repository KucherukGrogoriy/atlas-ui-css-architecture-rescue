Atlas UI — CSS Architecture Rescue
Практическая работа №6 . Проект представляет собой рефакторинг CSS-архитектуры библиотеки компонентов после слияния с legacy-виджетом подрядчика.
Запуск проекта
Убедитесь, что у вас установлен Node.js версии 18 или выше.
1. Установите зависимости: npm install
2. Запустите локальный сервер: npm run dev
3. Откройте в браузере http://127.0.0.1:5173
   Тестирование
   В проекте настроены структурные тесты архитектуры (18 проверок) и браузерные тесты (Playwright).
   Запуск структурных тестов: npm test
   Запуск браузерных тестов: npm run test:e2e
   Что было сделано (Архитектурные решения)
* Управление каскадом: Внедрены @layer (reset → legacy → vendor → tokens → base → components → states → utilities). Legacy-стили изолированы в слое legacy.
* Изоляция: Убраны глобальные классы-утечки (.is-danger), убраны ID (#workbench) из селекторов.
* Токены: Все жестко заданные цвета (hex, rgba) заменены на семантические CSS-переменные для поддержки двух тем.
* Доступность (A11y): Переключатели переведены на паттерн визуального скрытия (доступны с клавиатуры). Добавлен :focus-visible для кнопок и полей. Модальное окно открывается через showModal().
* Адаптивность: Убраны жесткие min-width, ломавшие сетку на 320px. Карточки корректно перестраиваются на мобильных.
  Отчетность
  Все заполненные шаблоны (Аудит, ADR, Матрица тестов, Регрессионный отчет) находятся в папке reports/. Скриншоты «До» и «После» находятся в reports/screenshots/. Документация CSS API находится в reports/API.md.
