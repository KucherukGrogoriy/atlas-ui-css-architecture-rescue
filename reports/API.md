# Atlas UI — CSS API Documentation

## 1. Кнопки (`.ui-button`)
**Базовый класс:** `.ui-button`
**Модификаторы (варианты):**
* `.ui-button--primary` — основное действие (синий)
* `.ui-button--secondary` — вторичное действие (светлый фон, рамка)
* `.ui-button--ghost` — тихое действие (прозрачный фон)
* `.ui-button--danger` — опасное действие (красный)

**Размеры:**
* `.ui-button--sm` — маленькая
* `.ui-button--lg` — большая (без модификатора — стандартная)

**Состояния (не требуют классов, работают нативно):**
* `:hover` — при наведении
* `:focus-visible` — при навигации с клавиатуры (синяя рамка)
* `:active` — при нажатии
* `disabled` — атрибут HTML для блокировки

## 2. Поля (`.ui-field`)
**Обертка:** `.ui-field`
**Внутри:** `input`, `textarea` (стилизуются автоматически).
**Состояние ошибки:** добавляется атрибут `aria-invalid="true"` на инпут, CSS подсветит рамку и текст подсказки `.ui-field__hint`.

## 3. Карточки (`.ui-card`)
**Базовый класс:** `.ui-card`
**Модификатор:** `.ui-card--featured` (выделенная рамка)
**Сетка:** оберни карточки в `.card-grid`.

## 4. Доступные CSS-переменные (Токены)
Для переопределения темы используй переменные из `:root`:
* `--color-accent` (основной цвет)
* `--color-danger` (цвет ошибки)
* `--color-surface` (фон карточек)
* `--color-ink` (цвет текста)
* `--radius-md` (скругление)
